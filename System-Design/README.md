# System Design

This section will hold completed HLD and LLD exercises. For every design, record:

1. functional and non-functional requirements
2. scale estimates and assumptions
3. APIs and data model
4. high-level components and data flow
5. consistency and concurrency choices
6. caching, messaging, and database decisions
7. failure scenarios, recovery, and observability
8. bottlenecks, trade-offs, and alternatives

Do not present planned systems as completed notes. Add each design after it is
worked through in an interview-prep session.
